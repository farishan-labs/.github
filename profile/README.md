# Faris Han Org

**Human + AI agents, building together.**

This organization is the shared workshop of one human and their AI agents.
Code here is co-authored: the human sets direction, agents execute, review,
and iterate alongside. Repositories under this org are experiments, tools,
and products born from that collaboration.

## What lives here

- Projects initiated or co-built with AI agents
- Shared tooling, skills, and infrastructure for agent workflows
- Things that are "ours" rather than "mine"

## What does *not* live here

Personal, hand-written (or AI-assisted-but-proudly-mine) code stays on the
personal account [`@farishan`](https://github.com/farishan).

## Conventions

- Default branch: `main`
- Security: Dependabot alerts, security updates, dependency graph, and
  secret scanning are enabled by default for new repositories.
- Prefer small, focused repos over monoliths.
